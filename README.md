# Localmodel

Собственная виртуальная героиня, один танец, несколько аниме-вдохновлённых образов.
Код генерирует изображения и клипы через API, затем сам собирает вертикальный ролик
под музыку. Ручной монтаж в видеоредакторе не нужен.

## Статус 0.1.0

Работает локальная автосборка: анализ музыки, выбор переходов, обрезка по общей
шкале танца, экспорт MP4, проверка числа кадров и сохранение отчёта.
Есть REST-адаптеры FLUX.2, FLUX.2 Edit и Kling Motion Control через fal.
**Настоящие платные генерации ещё не выполнялись.** Контракты адаптера проверены
тестовыми ответами; качество лица, одежды и переноса движений пока не подтверждено.

Название репозитория не означает локальный запуск весов нейросетей:
в 0.1 монтаж выполняется на компьютере, генерация выполняется в облаке fal.
ComfyUI/Wan, обучение собственной LoRA и локальное выполнение моделей пока не реализованы.
Здесь «своя героиня» означает собственный виртуальный персонаж, а не обучение модели с нуля.

## Быстрый запуск в Windows PowerShell

Нужен установленный Python 3.12. Docker, WSL, активация окружения и права
администратора для этих команд не требуются. Доступ к PyPI нужен при установке.

```powershell
git clone https://github.com/Evolut10n11/localmodel.git
cd localmodel
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m localmodel doctor
.\.venv\Scripts\python.exe -m localmodel demo
```

Результат: `workspace/demo/final.mp4`. Для просмотра:

```powershell
Invoke-Item .\workspace\demo\final.mp4
```

`demo` создаёт три синтетических диагностических клипа и тестовую звуковую дорожку,
затем действительно кодирует итоговое видео. Это проверка монтажа, не ролик с
AI-девушкой. Интернет, API-ключ и оплата при запуске demo не используются.
FFmpeg поставляется в wheel `imageio-ffmpeg`, отдельная системная установка и ffprobe
не нужны. Для собственного FFmpeg предусмотрена переменная `IMAGEIO_FFMPEG_EXE`.

Альтернативно после клонирования можно запустить `start-demo.ps1`, если локальная
политика PowerShell разрешает запуск скриптов. Обходить системные политики не требуется.

## Что делает код

```text
описание оригинальной героини -> FLUX.2 -> character.png
character.png + описания одежды -> FLUX.2 Edit -> looks/*.png
каждый образ + один подготовленный танец -> Kling Motion Control -> clips/*.mp4
музыка -> найденные биты -> монтажный план -> FFmpeg -> final.mp4
```

В первой версии каждый образ показывается один раз, в порядке `[[looks]]`.
Переходы выбираются около равномерных точек ролика и смещаются к найденным битам
в пределах 0.6 секунды. Границы округляются до кадров. Если биты не найдены,
используются равномерные переходы; это явно отмечается в `timeline.json`.
Это не распознавание музыкальных фраз и не гарантированное определение сильных долей.

Для 12 секунд и трёх образов генерируется **три полных 12-секундных танца**.
Монтаж берёт, например, секунды 0–4 из первого, 4–8 из второго и 8–12 из третьего.
Нельзя перезапускать каждый исходный клип с нулевой секунды: это нарушает танец.
Этот контракт отдельно проверяется тестом на движущемся изображении.

## Первая реальная генерация

### 1. Настроить проект и посмотреть объём запросов

В `project.toml` уже есть стартовый дизайн вымышленной взрослой героини и три образа:
розовый, жёлтый и синий. Внешность пока не утверждена; описание можно изменить
до генерации. Пути считаются от расположения TOML, не от текущего каталога терминала.

```powershell
.\.venv\Scripts\python.exe -m localmodel plan
New-Item -ItemType Directory -Force .\workspace\input | Out-Null
```

План покажет 1 исходное изображение, 3 изображения образов и 36 секунд видео
для 12-секундного финала. Это количество запросов, **не расчёт стоимости**.
Перед оплатой проверьте текущие тарифы и доступность моделей в своём аккаунте fal.

Подготовьте `workspace/input/dance.mp4` и `workspace/input/music.mp3`.
Нужен чистый танец в полный рост, один человек, статичная камера, без титров и
перекрытий. Музыка должна соответствовать танцу. Параметры `dance_start` и
`music_start` позволяют выбрать согласованные начальные таймкоды без ручного монтажа.
Видеопример из TikTok в репозиторий не включён и автоматически не используется.

### 2. Ввести ключ локально

Ключ вводится скрыто и хранится только в переменной текущего процесса PowerShell:

```powershell
$secret = Read-Host "FAL API key" -AsSecureString
$env:FAL_KEY = [System.Net.NetworkCredential]::new("", $secret).Password
Remove-Variable secret
```

Не вставляйте ключ в чат, TOML, исходники или GitHub. `.env` автоматически не читается.
`--allow-paid` означает разрешение платной генерации и отправки исходников
облачному провайдеру. Без него команда не отправляет запрос.

### 3. Создать и утвердить героиню

```powershell
.\.venv\Scripts\python.exe -m localmodel generate character --allow-paid
Invoke-Item .\workspace\elaine\character.png
```

Проверьте внешность до генерации видео. Это просмотр результата, а не монтаж.
Можно использовать собственный готовый референс вместо генерации: сохраните
изображение PNG в `workspace/elaine/character.png` и начните с этапа `looks`.
Не запускайте `generate character` поверх такого файла: программа защищает исходники.

### 4. Создать образы и проверить один танец

```powershell
.\.venv\Scripts\python.exe -m localmodel generate looks --allow-paid
.\.venv\Scripts\python.exe -m localmodel generate clips --look pink --allow-paid
Invoke-Item .\workspace\elaine\clips\pink.mp4
```

Сначала оцените один клип: лицо, кисти, силуэт, одежду и соответствие движений.
Только после этого имеет смысл оплачивать остальные клипы:

```powershell
.\.venv\Scripts\python.exe -m localmodel generate clips --allow-paid
.\.venv\Scripts\python.exe -m localmodel render
Invoke-Item .\workspace\elaine\final.mp4
```

Успешно сохранённый `pink.mp4` с теми же параметрами повторно не заказывается.
После окончания работы ключ можно удалить из переменной окружения:

```powershell
Remove-Item Env:FAL_KEY
```

## Защита файлов, запросов и бюджета

`*.job.json` рядом с результатом хранит отпечатки входных файлов и параметров,
ID облачного запроса, статус и SHA-256 результата. При повторе с теми же входами
программа использует готовый файл либо продолжает проверку того же запроса.

POST генерации автоматически не повторяется. Если соединение оборвалось в момент
отправки и ID неизвестен, программа останавливается. Сначала проверьте историю fal:
новая попытка без этой проверки может оплатить дубликат. Не удаляйте job-файлы
для «починки» вслепую. При изменении промптов или входных файлов используйте новый
`workdir`, например `workspace/elaine-v2`, сохраняя результаты прошлого эксперимента.

Локальный тайм-аут или Ctrl+C **не отменяет** уже запущенную облачную задачу.
Она может завершиться и тарифицироваться. Автоматическая отмена и жёсткий лимит
расходов в валюте пока не реализованы. Нет автоматического перебора вариантов,
скрытых повторов генерации, параллельных платных задач или запуска моделей в CI.

Для одного `workdir` используется файловая блокировка. После аварийного завершения
проверяйте, что другого процесса нет, прежде чем удалить `.running.lock`.
Это локальный CLI, а не многопользовательский сервис.

Файлы передаются как Base64 data URI согласно контракту fal. Для одного входного
файла установлен локальный лимит 32 МиБ. При ошибке размера на стороне провайдера
потребуется уменьшить разрешение/длительность либо добавить адаптер загрузки файлов.
Ключ передаётся только на `queue.fal.run`; HTTP redirects запрещены. При скачивании
результатов ключ не отправляется. Результаты и исходники остаются в игнорируемом
`workspace/`; URL результатов в fal могут быть публично доступны по ссылке.

## Проверки и ограничения

Тесты запускаются локально:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

На исходной реализации: 49 тестов прошли под Linux, Python 3.13.5.
Проверены реальное кодирование MP4, 180 кадров при 30 fps, AAC-звук,
отсутствие перезапуска танца на склейках, короткие исходники, защита путей,
кэширование запросов, продолжение ожидания и запрет повторного POST после сбоя.
Windows PowerShell предусмотрен инструкцией и кодом, но на Windows эта версия
ещё не запускалась. Установка зависимостей с нуля в этой среде не проверена.
Подробности: `docs/VERIFICATION.md`.

Нормализация FFmpeg не исправляет различия поз, которые внесла модель.
Один seed не гарантирует одинаковое лицо. Автоматическая проверка узнаваемости,
кистей и временного совпадения движений пока отсутствует; после генерации
нужно визуально оценить клипы. Слишком короткие клипы и музыку программа отклоняет,
не скрывая проблему зацикливанием или замораживанием последнего кадра.

Для собственных публикаций нужны разрешённые к использованию музыка, танец и
изображения. Используйте оригинальную вымышленную взрослую героиню или референсы
людей с их согласием. Автопубликации и удаления водяных знаков в проекте нет.

## Дальнейшая работа

Следующий этап: реальный тест одной героини и одного танца с согласованным бюджетом,
затем проверка узнаваемости в трёх образах. После подтверждения качества:
оценка поз на переходах, автоматический выбор удачных фрагментов, оформление
стикерами и русскоязычный интерфейс. Локальный адаптер ComfyUI/Wan рассматривается
отдельно после проверки доступной GPU и её памяти.
